# Frontend Pages

This document lists the primary full-page views in Krayin CRM.

- **Dashboard**: (`/admin/dashboard`) Visual metrics, pipeline stages summary, recent activities.
- **Leads Kanban**: (`/admin/leads`) Drag-and-drop board of leads.
- **Leads DataGrid**: (`/admin/leads?view=list`) Tabular list of leads.
- **Lead Detail**: (`/admin/leads/view/{id}`) Split view containing static data, custom attributes, and the Activity Timeline.
- **Persons Index**: (`/admin/contacts/persons`)
- **Organizations Index**: (`/admin/contacts/organizations`)
- **Activities Index**: (`/admin/activities`)
- **Campaigns Index**: (`/admin/campaigns`)
- **Settings Dashboard**: (`/admin/settings`) Grid of configuration options (Users, Roles, Attributes, Tags, Pipelines, Sources).
